## ADDED Requirements

### Requirement: Interactive carousel editor
The system SHALL provide a dashboard interface where users can input topics, view the elaboration, and edit the final generated slides.

#### Scenario: Editing slide content
- **WHEN** a user clicks on a slide in the preview
- **THEN** it becomes editable, allowing the user to manually override the AI-generated text.

### Requirement: Live slide preview
The system SHALL render a real-time preview of the carousel slides as they are being generated or edited.

#### Scenario: Real-time update
- **WHEN** slide text is changed
- **THEN** the visual preview updates immediately to reflect the new text.
